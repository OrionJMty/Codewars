# Codewars
Решение задач с Codewars
Для каждый задачи свой каталог с названием каты в котором будет:
файл `README.md` с описанием каты:
1. Имя и уровень каты (`# Name (8kyu)`)
2. Ссылка на кату
1. Задание на английском и перевод на Русский

`solution_cpp17.cpp` Решение для с++17
`solution_cpp23.cpp` Решение для с++23

One folder per solved kata: `<kyu>_<slug>/solution_cpp17.cpp + solution_cpp23.cpp + README.md`.

`README.md` per kata, always in this shape:

1. Kata name with level (`# Name (8kyu)`)
2. Link to the kata
3. Task description in English, then its Russian translation below

`solution_cpp17.cpp` c++17 solution;
`solution_cpp23.cpp` c++23 solution
